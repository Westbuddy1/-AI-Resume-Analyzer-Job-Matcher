# 🤖 AI Resume Matcher

An AI-powered application that analyzes resumes and matches them with job descriptions using NLP and semantic similarity.

## Features
- Resume & job description comparison
- AI-based match scoring
- Skill gap detection
- FastAPI backend

## Tech Stack
- Python, FastAPI
- Sentence Transformers
- spaCy
- React (Frontend)

## How to Run
```bash
pip install -r backend/requirements.txt
uvicorn backend.main:app --reload
